# Code of Conduct

We are committed to a respectful, constructive and accessible learning community.

Examples of expected behavior:
- Be respectful of different backgrounds and experience levels.
- Give specific, actionable feedback about code and explanations.
- Assume good intent while remaining precise about technical correctness.
- Keep discussions focused on improving the project and its learning value.

Unacceptable behavior includes harassment, discrimination, personal attacks, doxxing, threats, or persistent disruptive conduct. Project maintainers may remove content or participation that violates these standards.

Report concerns privately to the repository maintainers.
