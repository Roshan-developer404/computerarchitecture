CPU performance playground

MODULE 6 · S83–S88
5,000 ns · 5 μs

CPU time = Instruction Count × CPI × Clock Period. For a basic single-cycle processor, CPI is approximately 1, but the clock period must be long enough for the slowest instruction path. A pipeline improves throughput by overlapping instructions; cache reduces average memory-access delay. These solve different performance problems.

Single-cycle processor

One instruction completes per cycle. CPI ≈ 1, but the clock period is constrained by the longest instruction datapath (often a load path in a basic design).

Pipelined processor

Instruction work is divided into IF, ID, EX, MEM and WB stages. Different instructions overlap in different stages; ideal throughput approaches one completed instruction per cycle after the pipeline fills.

Cache memory

Small, fast storage near the CPU exploits temporal and spatial locality. Cache hits avoid many slower main-memory accesses and reduce average memory-access time.
